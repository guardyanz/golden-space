# Shared brief

Create a polished portrait 4:5 social-media promotion for Golden Space, an open-source
design skill for AI agents. The audience is developers and designers working with AI.
Use a sculptural arch and a sphere, matte tactile materials, and the same palette:
warm ivory, deep forest green, and a restrained terracotta accent.

Final copy, typeset separately as live SVG text in both versions:

- Golden Space.
- Design skill for AI agents
- Better space. Clearer design.
- Whitespace / Proportion / Editable SVG
- Explore the repo
- github.com/guardyanz/golden-space
- Open source / MIT

Final posts are 1080 x 1350. Generate the artwork layer without lettering so that
wording stays accurate and editable. Use one generated artwork sample per version,
the same built-in image-generation tool, and no input reference image.
