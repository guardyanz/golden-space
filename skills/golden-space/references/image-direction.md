# Directing poster and image generation

Use this reference when the requested medium needs an image-generation or editing
tool. The composition guidance still applies to the generated result. Follow the
available tool's usage instructions; this skill does not supply an image model.
For vector-suitable artwork, construct SVG directly using the SVG contract instead.

## Make constraints visible in the brief

Translate the content into concrete visual relationships before calling the tool.
Include the subject, medium, aspect ratio, focal placement, relative scale, breathing
room, supporting detail, palette, and intended viewing size. For photography, include
light and depth only as they support the subject and requested style.

Describe where whitespace belongs and what it protects. For example, reserve a quiet
upper-left region for a short headline and place the subject lower-right. Avoid
"use whitespace" with no spatial direction. Keep essential content inside sensible
safe margins, accounting for any known crop or platform overlay.

Choose a grid or proportion that fits the subject. If using a golden relationship,
describe the actual placement or size relationship rather than asking for a visible
golden spiral. A thirds-based or centered composition can be more appropriate.
Do not force exact geometric claims onto a generated raster image unless measured.

Describe useful exclusions tied to the brief: competing focal points, clutter in a
protected copy zone, accidental edge crops, or illegible small lettering. Preserve
intentional density and ornament in styles that need them. Negative space need not
be blank white or visually empty.

## Copy and typography

When exact wording and editability matter, keep typography in the SVG layout and
generate the photographic or painted artwork separately. Place live text over a
quiet region in a clearly identified hybrid composition, or deliver the raster
artwork and an editable vector layout as separate files. Do not call either option
a fully vector recreation of the photograph.

If the requested raster output includes generated text, inspect the spelling,
spacing, hierarchy, and size. Correct visible errors with available editing or
typesetting tools. Do not claim the text is editable just because the image has
been saved in a different container format.

## Example of concrete direction

For a ceramic exhibition image, direction might be:

> Portrait editorial photograph of one handmade ceramic vessel in the lower-right
> region, warm mineral colors, soft side lighting, a simple matte background,
> generous quiet space across the upper-left for the exhibition title, and clear
> clearance from the crop edges. Keep supporting props subordinate. No lettering
> in the photographic layer; the final title will be typeset separately.

This is an example of mapping principles to placement. It is not a style template
for every image. An abstract concert poster or a dense product illustration should
have different direction appropriate to its message.

## Review the result and deliver

Inspect the generated image at intended size and in a smaller preview. Check the
focal point, hierarchy, breathing room, color relationships, protected copy region,
and cropping. For realistic subjects, also check visible anatomy, perspective, and
object integrity when relevant. Revise the most consequential observed issue with
available tools within the user's scope and any stated generation budget.

Deliver the actual artifact requested. An image prompt alone is sufficient only
when the user asked for a prompt or generation is unavailable; explain the latter
without pretending an image was produced. Likewise, an editable SVG request needs
an actual SVG artifact or complete source, not a promise to export later.
